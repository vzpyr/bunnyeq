Using Linux?

You probably need udev rules so the browser can open the HID interface (WebHID uses hidraw), then replug the device. 

sudo tee /etc/udev/rules.d/99-bunny.rules <<'EOF'
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="31b2", MODE="0666"
EOF
sudo udevadm control --reload-rules
